## 3. Promotional Asset Guidelines

When capturing or generating new promotional assets:
1. **Real Screenshots Only:** Never fabricate interface mockups or generate AI-hallucinated screenshots that do not match the real deployed Vercel templates.
2. **Aspect Ratio:** Maintain a consistent 16:9 or 16:10 aspect ratio across all catalog preview cards.
3. **Format & Compression:** Export master screenshots in lossless PNG, then optimize into modern WebP with 85% quality compression to ensure ultra-fast load times.
4. **No Artificial Distortion:** Avoid heavy perspective skewing or extreme drop shadows that obscure the actual user interface of the templates.
