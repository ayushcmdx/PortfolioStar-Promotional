# PortfolioStore 99 — Business Overview

## 1. Executive Summary

**PortfolioStore 99** ([portfoliostore99.in](https://www.portfoliostore99.in)) is an independent digital storefront that sells production-ready, unbundled personal portfolio website templates to software developers, computer science students, designers, and tech creators.

The platform was created to eliminate the friction, recurring expense, and code lock-in associated with building a modern personal portfolio. Rather than paying recurring monthly subscriptions to proprietary website builders or spending weeks designing a site from scratch, customers can preview real, live-deployed portfolio designs and purchase complete, unbundled source code for a flat, one-time fee starting at **₹99**.

---

## 2. The Problem It Solves

### A. The Subscription Trap of Modern Site Builders
Popular website building platforms (such as Framer, Webflow, Squarespace, and Wix) charge recurring fees ranging from ₹1,200 to ₹3,500+ per month ($15 to $40/month) simply to keep a custom domain connected to a personal portfolio. For students, junior developers, and job seekers, these recurring costs accumulate quickly without providing ownership of the underlying codebase. If the subscription lapses, the portfolio disappears.

### B. The Time and Design Deficit
Engineers often spend weeks or months attempting to build an impressive portfolio from scratch. They frequently get bogged down in responsive edge cases, cross-browser CSS bugs, animation performance issues, and 3D graphics rendering rather than focusing on their actual projects, job applications, or client work.

### C. The Low Quality of Generic Free Templates
Many freely available portfolio templates scattered across GitHub or free theme directories suffer from:
- Outdated dependencies and abandoned frameworks.
- Broken responsive layouts on mobile devices.
- Lack of modern interactive features (e.g., 3D WebGL scenes, Spline integrations, dark/light theme persistence, terminal emulators).
- Absence of live, working interactive preview deployments.
- Zero support or setup documentation.

---

## 3. The PortfolioStore 99 Solution

PortfolioStore 99 delivers a straightforward, developer-friendly alternative:

1. **True Code Ownership:** Customers purchase complete source code archives (React, Next.js, Vite, Three.js, Tailwind CSS) that they can run locally, modify freely, version-control in their own GitHub repositories, and host for **free** on platforms like Vercel, Netlify, or GitHub Pages.
2. **Transparent One-Time Pricing:** All templates are sold under flat, one-time price tiers:
   - **Newbie Tier:** ₹99 flat (~$1.99 USD)
   - **General Tier:** ₹199 flat (~$3.99 USD)
   - **Premium Tier:** ₹399 flat (~$7.99 USD)
   Zero recurring subscriptions, hidden fees, or maintenance retainers.
3. **Live Deployed Previews:** Every template in the store has a dedicated, production-deployed preview URL on Vercel. Visitors can interact with animations, test theme toggles, inspect responsiveness, and verify features *before* paying.
4. **Automated Digital Delivery:** Once payment is completed via Razorpay Standard Checkout (supporting UPI QR, Google Pay, PhonePe, Paytm, Debit/Credit Cards, and Netbanking), the customer is immediately provided with a secure Google Drive delivery link and receives an order confirmation receipt via email.
5. **Human Support:** Direct setup guidance is available via WhatsApp (`@ayushcmd`) and email (`portfoliostore99@gmail.com`).
